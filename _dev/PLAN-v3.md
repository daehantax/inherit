# 상속세 플랫폼 계획서 v3 — 쉽게 쓰고, 절세로 이어지고, 신고는 우리가

작성 2026-10-18 · 대한세무법인 · 사이트 https://daehantax.github.io/inherit/
(원본: Claude 문서 「상속세 플랫폼 계획서 v3」. 이 파일은 저장소용 사본이며, 10장 진행 상황은 2026-10-18 오후 기준.)

## 1. 한 줄 결론

**홈택스는 "신고"만 해 주지만, 우리는 "상속 이후 5년의 세금"까지 보여 주고, 원하면 세무사가 대신 신고합니다.** 이 한 문장이 플랫폼의 전부이고, 모든 화면·문구·결제 지점은 이 문장을 뒷받침하는 데만 씁니다. 그 외 기능은 뺍니다.

홈택스보다 나은 점 4가지 (랜딩 첫 화면에 이 순서로):

| 홈택스는 | 우리는 | 고객이 얻는 것 |
| --- | --- | --- |
| 상속세 한 가지만 신고 | 상속세 → 취득세 → 재산세·종부세 → 양도세·분양권까지 한 번에 계산 | "지금 어떻게 나누느냐"가 5년 뒤 세금을 바꾼다는 걸 숫자로 봄 |
| 공제를 알아서 챙겨 주지 않음 | 입력값에 맞춰 절세 포인트를 자동으로 띄움 | 배우자공제·동거주택·금융재산·감정평가 등 놓치기 쉬운 공제를 챙김 |
| 용어 설명 없음 | 입력 칸마다 "꼭 알아야 할 것" 1줄 + ▶ 영상 | 모르는 말 때문에 멈추지 않음 |
| 본인이 직접 신고 | 결제하면 세무사가 검토하고 전자신고 파일로 직접 신고 | 실수 걱정 없이 끝냄 |

설계 원칙 3가지:

1. **입력은 최소로.** 꼭 필요한 칸만 먼저 보이고, 나머지는 "더 있어요?"로 접어 둡니다.
2. **말은 쉽게.** 세법 용어는 화면에 쓰지 않고, 9장 치환표의 고객 말로만 씁니다. 법 용어는 물음표 안에만 둡니다.
3. **결제는 제안으로.** 무료로 끝까지 볼 수 있고, 결제 버튼은 "이걸 대신 해 드릴까요?"라는 제안으로만 나타납니다. 가로막는 결제창은 없습니다.

## 2. 고객 여정 5단계

고객은 다섯 화면을 순서대로 지나갑니다. 돈을 내는 곳은 4단계 한 곳뿐이고, 그 앞까지는 전부 무료입니다.

| 단계 | 화면 이름(고객 말) | 고객이 하는 일 | 화면 맨 위 한 줄 | 비용 |
| --- | --- | --- | --- | --- |
| 1 | 무엇을 물려받나요 | 가족·집·땅·예금·빚·장례비·사전증여를 입력 (`estate.html`) | "아는 것만 적으세요. 모르는 칸은 비워두셔도 됩니다." | 무료 |
| 2 | 세금은 얼마인가요 | 상속세 + 취득세 + 재산세·종부세 + 나중에 팔 때 양도세를 한 화면에서 봄 | "지금 내는 세금과, 앞으로 낼 세금을 함께 보세요." | 무료 |
| 3 | 줄일 수 있나요 | 입력값에 맞는 절세 포인트 최대 7개, 각각 예상 절감액 + ▶ 영상 | "이 상황에서 챙길 수 있는 것만 추렸습니다." | 무료 |
| 4 | 세무사에게 맡기기 | (선택) 셀프 신고서 / 검토 상담 / 신고 대행을 신청·결제 | "직접 하셔도 됩니다. 맡기시면 이렇게 진행됩니다." | 9만9천원 / 33만원 / 신고 대행 견적 |
| 5 | 신고 끝, 그 다음 | 접수증 확인, 취득세 납부 기한, 다음 해 재산세·종부세, 팔 때 할 일 달력 | "상속세는 끝이 아니라 시작입니다. 날짜만 기억하세요." | 무료 |

지금 사이트와의 차이: 예전에는 "간단계산 → 셀프 절세 → 세무사 문의"가 세 페이지로 나뉘어 같은 값을 다시 채우게 됐습니다. v3에서는 **1단계에서 한 번 입력한 값(상속 파일)이 2·3·4·5단계를 모두 태웁니다.** 기존 셀프 절세(inheritGold)의 20단계 계산기는 없애지 않고 3단계 뒤에 "자세히 계산" 링크로 남깁니다.

## 3. 입력 화면 설계 (1단계 · estate.html)

필수 입력은 **12칸**이면 결과가 나옵니다. 나머지는 접혀 있고, 펼칠수록 결과가 정확해집니다. 한 화면에 질문 하나씩, 폰에서 엄지로 넘기는 카드 형식입니다.

| 화면 | 질문(그대로 표시) | 필수 칸 | 접힌 칸("더 있어요?") | 티칭 포인트 ID |
| --- | --- | --- | --- | --- |
| A 가족 | 누가 돌아가셨고, 누가 물려받나요? | 돌아가신 날, 배우자 있음/없음, 자녀 수 | 미성년 자녀 나이, 65세 이상, 장애인(기대여명 도우미), 손자녀가 받는 금액, 지금 가진 집(세대 전체) | T01, T02, T03 |
| B 집·땅 | 집과 땅은 무엇이 있나요? (한 채씩 추가) | 종류(아파트/단독/상가/땅/분양권), 시가 또는 공시가 | 공시가, 감정평가 여부, 돌아가신 분과 같이 살았나, 향후 판매 계획, 지역·면적 | T04, T05, T06, T07 |
| C 예금·기타 | 예금, 주식, 보험금, 차는 얼마인가요? | 금융재산 합계 | 보험금(피보험자·계약자), 퇴직금, 차량, 회원권, 빌려준 돈 | T08, T09, T10 |
| D 빚·장례비 | 갚아야 할 돈과 장례비는요? | 빚(대출·전세보증금), 장례비 | 밀린 세금·공과금, 병원비, 봉안시설비 | T11, T12 |
| E 미리 준 재산 | 10년 안에 가족에게 미리 준 재산이 있나요? | 있음/없음 | 받은 사람, 날짜, 금액, 낸 증여세 · **돌아가신 분이 10년 안에 상속받은 재산(단기재상속)** | T13, T14, T15, T25 |
| F 나누기 | 누가 무엇을 받나요? (기본값: 법정 비율) | 없음 — 기본값으로 바로 통과 가능 | 재산별로 받는 사람과 지분 | T16, T17, T18 |

화면 F가 이 플랫폼의 핵심입니다. 여기서 "누가 받느냐"를 바꾸면 2단계의 네 가지 세금이 동시에 다시 계산됩니다. 홈택스에는 이 화면이 없습니다.

입력 화면 규칙:

- 한 칸에 한 질문. 단위는 "만원"으로 받고 올리면 "3억 5,000만원"으로 바로 보여 줍니다.
- 모르면 비워 도 됩니다. 빈 칸은 결과 화면에 "이 값을 넣으면 더 정확해집니다"로 나타납니다.
- 오른쪽(폰에서는 아래) 요약 패널: 입력할 때마다 "지금까지 재산 7억 2,000만원 · 예상 상속세 약 1,900만원"이 같이 움직입니다.
- 주민등록번호·계좌번호·정확한 주소는 고객 화면에서 받지 않습니다. 신고 대행을 결제한 뒤 세무사가 별도로 받습니다(8장 개인정보).
- 입력은 키를 누를 때마다 이 기기에 저장되고, "링크 복사"로 가족에게 그대로 보낼 수 있습니다.

## 4. 티칭 포인트 (꼭 알아야 할 것 + ▶ 영상)

티칭 포인트는 입력 칸 옆 물음표가 아니라 **칸 아래 한 줄 문장**입니다. 한 줄을 읽고 더 알고 싶으면 ▶를 누릅니다.

```
배우자가 있나요?   ( ) 있음  ( ) 없음
💡 배우자가 있으면 최소 5억원이 더 공제됩니다. 단, 실제로 받아야 합니다.  ▶ 2분 영상
```

영상 연결 규칙:

- 한 포인트 = 영상 하나 + 시작 초. `js/teach.js` 목록의 `video`, `t` 칸에 넣으면 바로 켜집니다. 코드 수정 없음.
- 영상이 아직 없으면 ▶는 숨기고 한 줄만 보입니다.
- ▶를 누르면 페이지를 떠나지 않고 작은 창에서 재생됩니다(입력값 유지).
- 열어 본 포인트는 상속 파일에 기록되어(`opened`) 세무사 문의에 함께 넘어갑니다.

## 5. 절세 포인트 (3단계 "줄일 수 있나요")

절세 포인트는 고객 입력값에 조건이 맞을 때만 뜨고, **뜨면 반드시 금액이 붙습니다.** 금액은 같은 계산 함수(`EC.calcAll`)를 "지금" 과 "바꾼 뒤"로 두 번 돌려 차이를 구하므로 계산과 어긋날 수 없습니다. 한 번에 최대 7개, 금액 큰 순서.

```
① 배우자가 더 받으면                          약 1,840만원 ↓
지금은 배우자가 3억원을 받는 걸로 계산했습니다. 7억 2,000만원까지 받으면
상속세가 이만큼 줄어듭니다. 단, 배우자가 나중에 돌아가실 때 다시 상속세가 나옵니다.
[이렇게 바꿔서 다시 계산]   ▶ 영상 2분   [세무사에게 물어보기]
```

### 5-1. 상속세 자체 절세 포인트 (`js/savings.js`)

| 코드 | 고객이 보는 제목 | 뜨는 조건 | 금액 계산 | 세무사 확인 |
| --- | --- | --- | --- | --- |
| S01 | 배우자가 더 받으면 | 배우자 수령액 < 법정지분 한도(최대 30억) | 수령액을 한도까지 올렸을 때 세액 차이 | 2차 상속 언급 필수 |
| S02 | 같이 살던 집은 같이 살던 자녀가 | 동거 10년 이상 무주택 자녀, 1주택 | 동거주택공제(집값−담보채무, 최대 6억) | 미성년 기간 제외 |
| S03 | 집을 감정평가 받으면 | 공시가 평가 부동산 + 향후 판매 계획 | 양도세 절감 − 상속세 증가 − 감정료(감정가 = 지금 시세) | 국세청 감정평가 대상 |
| S05 | 장례비 영수증을 모으세요 | 장례비 < 1,000만 | (1,000만−입력)×한계세율 | — |
| S07 | 손자녀 몫을 자녀가 받으면 | 손자녀 수령액 > 0 | 할증 vs 두 번 내는 세금 비교 | 유리한 경우도 있음 |

### 5-2. 연결 세금 절세 포인트 (홈택스에 없는 부분)

| 코드 | 고객이 보는 제목 | 뜨는 조건 | 금액 계산 | 세무사 확인 |
| --- | --- | --- | --- | --- |
| L01 | 집은 집 없는 자녀가 받으면 취득세가 줄어듭니다 | 세대 무주택 상속인 있음 | 공시가×(2.96%−0.96%), 주된 상속인 세대 기준 | 세대 기준 판단 |
| L02 | 집을 나눠 받으면 종부세에서 빠집니다 | 유주택 상속인이 전부 받음 | 지분 40% 이하로 나눌 때 6년째부터 차이 | 종부세령 4의2 |

### 5-3. 확인해 보세요 (금액 없음)

C01 대출 확인, C02 보증금, C03 연부연납·물납, C04 원래 집 먼저 팔기, C05 분양권, C06 재산세 6월 1일, C07 배우자 한도 초과, C08 추정상속, C09 다주택 중과 위험(2026.5.10 재적용), C10 단기재상속.

새 포인트는 `RULES` 배열에 한 덩어리(조건 + 바꾼 상속 파일 + 문구)를 더하면 화면에 나타납니다.

## 6. 결제 유도 설계

결제는 세 곳에서만 제안하고, 세 곳 모두 "고객이 방금 확인한 숫자" 바로 아래에 둡니다. 팝업·타이머·"오늘만 할인"은 쓰지 않습니다.

### 6-1. 상품은 셋 (2026-10-18 결정: 셀프 신고서 유지)

| 상품 | 고객 말로 | 가격 | 고객이 받는 것 | 우리가 하는 일 |
| --- | --- | --- | --- | --- |
| 셀프 신고서 | "신고서를 다 채워 드립니다. 직접 내시면 됩니다" | 9만 9천원 | 신고서 서식 전체(인쇄·PDF) + 칸별 입력 가이드 + 납부서 | 결제 확인 후 열쇠 코드 발급 → 서식 잠금 해제 |
| 세무사 검토 | "세무사가 한 번 봐 드립니다" | 33만원 (셀프 신고서 결제분 차감) | 입력값 검토 + 절세 포인트 확정 + 서면 답변서 + 30분 통화 | 상속 파일 열어 보고 답변서 작성 |
| 신고 대행 | "신고까지 맡기기" | 기본 99만원 + 10억 초과분 0.1% (앞 단계 결제분 차감) | 검토 포함 + 서류 안내 + 전자신고 + 접수증 + 취득세·종부세 달력 | 상속 파일 → 전자신고 파일 생성 → 세무대리인 계정 제출 |

세 상품은 계단입니다. 앞 단계에 낸 돈은 다음 단계에서 모두 빼 주므로 "일단 9만 9천원으로 시작"해도 손해가 없습니다. 상속세가 0원이면 신고 대행은 제안하지 않습니다. 가격은 `js/estate.js`의 `EST.PRICE` 한 곳에서 바꿉니다.

### 6-2. 제안이 나오는 세 지점

| 지점 | 직전에 고객이 본 것 | 문구 | 버튼 |
| --- | --- | --- | --- |
| 2단계 결과 맨 아래 | 상속세 + 연결 세금 합계 | "이 계산은 입력하신 값 기준입니다. 빈 칸을 채우시거나, 세무사가 한 번 봐 드릴 수 있습니다." | [빈 칸 채우기] [세무사가 봐 드립니다 · 33만원] |
| 3단계 절세 포인트 맨 아래 | 절감 가능액 | "적용되는지 확인하고 신고까지 맡기시면 예상 비용은 약 ○○만원입니다." → 절감액과 비용이 한 줄에 | [직접 신고할게요] [신고까지 맡기기] |
| 5단계 "그 다음" | 취득세 기한, 종부세 예상 | "날짜를 문자로 보내 드릴까요? (무료)" | [알림 받기] — 유료 제안 없음 |

절감액이 비용보다 작으면 이 줄을 띄우지 않고 "직접 신고하셔도 충분합니다"로 바꿉니다. 손해 보는 제안을 안 하는 게 신뢰를 만듭니다.

### 6-3. 결제 화면

1. 무엇을 받나 — 표 한 줄: 포함 내용, 기한, 비용.
2. 연락처 — 이름, 전화, 이메일. 주민번호 없음.
3. 결제 방법 — "계좌이체"(입금자명 = 접수번호) / "카드"(결제 링크 발송).
4. 접수 완료 — 접수번호 F-20261018-01, 서류 목록(상속 파일 기준 자동 생성), 같은 내용 이메일.

쓰지 않는 말: 전문가, 프리미엄, 최적화, 리스크. 쓰는 말: 봐 드립니다, 대신 해 드립니다, 이렇게 진행됩니다, 언제까지.

## 7. 신고 대행 흐름 (결제 후 우리가 하는 일)

```
고객 ──① 다시 보기 링크──▶ 사이트+시트 ──② 서류+주민번호(이메일·사무실)──▶ 세무사(efile.html) ──③ .01 파일──▶ 홈택스
  ▲                                                                                                      │
  └──────────────── ④ 접수증·납부서·다음 할 일 달력을 이메일로 ─────────────────────────────────────────────┘
```

민감정보는 ②에서 처음 들어오고, 세무사 기기의 `efile.html`에서만 쓰이며 사이트·시트·이메일 본문에는 남지 않습니다.

1. **접수** — 시트 「신고 접수」 탭에 한 줄(접수번호, 연락처, 비용, 다시 보기 링크, 상태=신청). 세무사에게 이메일.
2. **입금 확인** — 시트 상태 「입금」. 고객에게 자동 메일 + 서류 목록.
3. **서류 받기** — 가족관계증명서, 등기부등본, 잔액증명, 채무 증명, 장례비 영수증, 상속인 주민등록번호·주소, 협의분할서, (단기재상속) 그때 상속세 신고서.
4. **검토** — 「다시 보기」로 고객 입력값을 열어 평가액·공제·분할을 서류와 맞춰 수정.
5. **고객 확인** — 수정본 신고서 미리보기 PDF 발송, "이대로 신고해도 될까요?" 30분 통화.
6. **파일 만들기** — `efile.html`에서 상속 파일 + 민감정보 → 국세청 규격 `.01` 파일. 교차 검증 통과 전까지 다운로드 불가.
7. **제출** — 홈택스 세무대리인 계정 → 상속세 전자신고 파일 변환 → 오류 확인 → 접수증.
8. **마무리** — 시트 상태 「신고완료」 → 고객 메일.

처음 3건은 화면 입력으로도 신고해 금액이 같은지 대조합니다.

### 8-3. 계산 엔진 요점 (2026년 10월 시행 세법)

- 상속세: 과세가액 → 일괄/기초+인적, 배우자(법정지분 한도·30억), 동거주택(6억), 금융재산, 종합한도(§24) → 세율 → 세대생략 할증(§27, 미성년 20억 초과분 40% 개인별) → 증여세액공제(§28) → **단기재상속 세액공제(§30, 한도 = 산출세액−증여세액공제)** → 신고세액공제 3%(§69).
- 평가: 아파트·오피스텔은 시세, 땅·단독주택·상가는 공시가(감정평가 표시 시 시세).
- 취득세(공시가 기준): 2.8%+교육세, 85㎡ 이하 주택 농특세 없음, 무주택 특례 0.8%는 **주된 상속인 세대** 기준·상속주택 1채만, 오피스텔 제외.
- 재산세·종부세 10년: 상속주택 5년 주택 수 제외, 종부세 지분 40%·6억(수도권 밖 3억) 요건, 2027년 이후 현행법 유지 가정.
- 양도세: 취득가 = 상속 평가액, 1세대1주택은 받은 주택 전체로 판정, 다주택 5년 경과 매도는 「중과 가능」 표시(계산 미반영).

### 8-4. 결제·접수

- Apps Script `form='inherit-file'` → 탭 「신고 접수」, 접수번호 F-YYYYMMDD-NN, 상태 드롭다운(신청→입금→서류→검토→확인→신고완료). 상태 변경 메일은 `onStatusEdit` 트리거(사람이 한 번 설치).
- 열쇠 코드 = 접수번호의 HMAC 8자리, `doGet(?verify=)`로 확인. 셀프 신고서 서식과 칸별 입력 가이드가 열립니다.
- 결제 링크는 토스페이먼츠/네이버페이 결제링크 또는 계좌이체(입금자명=접수번호).

### 8-5. 전자신고 파일 (efile.html)

- 규격: 국세청 2026.10 설명서, EUC-KR 고정길이, 자료구분 01~12·19·20·23·24, CRLF, 파일명 `YYYYMMDDG101000.01`, 세무프로그램코드 9000(기타, 승인 불필요), 정기신고만.
- 교차 검산(과세가액, 공제한도, 상속지분율 합 100%, 상속인별 채무·공과금·장례비 합 = 04레코드, 납부세액) 통과 전 다운로드 불가.
- 법정동코드는 직접 입력 + 조회 링크(공개 자료가 2022년판이라 코드 변경 미반영).
- 실제 홈택스 업로드 검증은 세무대리인 계정으로 남아 있음.

## 11. 신고서 채우기 (2026-10-19 추가) — 셀프·검토·맡기기의 실제 작업 흐름

### 11-1. 왜
- 셀프 신고서·세무사 검토는 "신청"만으로 끝나면 안 된다. 신고서(서식)와 전산매체(국세청 규격)에 들어갈 **자산·부채를 건별로** 고객이 직접 적어야 한다.
- 1단계(무엇을 물려받나요)는 계산용 합계만 받는다(5분). 건별 입력은 상품을 고른 뒤 **「신고서 채우기」(filing.html)** 에서 받는다.

### 11-2. 화면 흐름
```
estate.html(1단계 합계) → result.html(세금·줄이기·맡기기)
   ├─ 셀프 신고서 카드 ─┐
   ├─ 세무사 검토 카드 ─┴→ filing.html?p=self|review  (1 사람 · 2 집·땅 소재지 · 3 예금·주식 건별 · 4 빚·공과금·장례비 건별 · 5 확인·다음)
   │                        └→ result.html?p=…#ask 신청(결제) → 시트 「신고 접수」 + 메일
   └─ 신고까지 맡기기 ──→ 바로 신청 (「신고서 채우기 내용을 함께 보냅니다」 체크, 선택)
셀프: 입금 확인 → 열쇠 코드 → 신고서 서식 자동 채움(별지·부표3·부표1·제9호) → 홈택스 제출 순서(filing 확인 화면) → 납부
검토: 시트 링크 → efile.html(세무사용)에서 고객 입력 미리 채움 → 서류로 주민번호·계좌·법정동코드 보완 → 서면 답변 + 신고서 PDF
맡기기: 위 + 전산매체 파일 → 홈택스 업로드
```

### 11-3. 데이터
- `상속 파일.filing` = { deceased, filer, heirs{id}, assets{id: 소재지·면적·지분·평가코드}, fin{deposit[]·stock[]·insurance[]·retire[]·car[]·other[]}, debts[], charges[], funeral[] } — 링크(#e=)에 실려 시트로 간다.
- 비밀 저장소 `dh.estate.secret.v1` = 주민등록번호·계좌번호 — **이 기기에만**. 링크·메일·시트에 절대 싣지 않는다. 셀프 신고서 인쇄에만 쓴다. 세무사는 서류로 받아 efile.html에서 넣는다(sessionStorage).
- 건별 합계 → 1단계 금액 동기화(FIL.sync): 예금/주식/보험/퇴직/자동차/기타 합계, 채무(01·04→은행 대출, 07·08→보증금, 그 밖→기타), 공과금, 장례비(1 일반/2 봉안). 1단계 칸은 잠기고 「신고서 채우기에서 고치기」 링크.
- 서식(EST.toReturn): 건별 한 행씩(주식은 수량×단가, 예금은 은행명+계좌), 4단계 신고인·피상속인 채움. 전산매체(EF.build): filing 값 위에 세무사 값 우선, 05·08·09·10·19 레코드 건별.
- 한도: 셀프·검토는 총 상속재산(사전증여 포함) 15억원 이하. 넘으면 카드 막힘 + 맡기기/문의 안내.
