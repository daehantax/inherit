Ⅰ. 홈택스 전자신고 파일제출 개요

1. 목적
  세무회계프로그램을 구입하여 사용하고 있는 사업자 또는 자체 전산시스템(ERP 등)을
갖추고 있는 사업자가 상속세 신고에 필요한 모든 자료를 전산관리하고 있는 경우 별도로
입력하는 절차 없이 전자신고 파일을 생성하여 전자신고 변환프로그램을 통해 변환한 후
홈택스(http://www.hometax.go.kr)를 통해 바로 전자신고 할 수 있도록 하기 위한
것입니다. (이를 전자신고 일괄변환방식이라 함)

《 일괄 변환방식 홈택스세금신고 절차 》
 세무회계 프로그램 등             전자신고 변환프로그램               국세청 홈택스 홈페이지
                   ⇒                         ⇒
신고자료        전자신고        전자신고 파일 변환하여
        →                                        신고서 전송    →   접수증 확인
 입력         파일생성         정상변환되었는지 확인




2. 파일 수록요령
 (1) 제출가능 O.S명 : MS-DOS, Windows 및 이와 호환되는 O.S
 (2) 파일구조 : LINE SEQUENTIAL(각 레코드마다 CR/LF값 삽입)
 (3) 수록명령어 : COPY
 (4) 전환방식(CONVERSION MODE) : ASCII CODE
 (5) 한글코드 : 2Byte완성형(KSC-5601 국가표준코드)
 (6) 파일 수록내용 : 상속세 신고서와 그와 함께 제출해야 하는 구비(첨부)서류 등
 (7) 파일설계 형태

5. 수록시 유의사항
① 한글로 표기되는 항목
- 한글항목에 한글 이외의 문자(한자, 영문자, 일본문자 등)을 표현하는 방법
외국문자는 반드시 소리나는 대로 한글로 표기합니다.
   (예) “新신 實名" → “신실명”
      “실명APT" → “실명아파트”

② 성명
- 좌측부터 수록하여, 우측에 남는 자리는 빈칸(Space)으로 둡니다.
- "성명" 란에는 반드시 한 사람의 순수한 성명만을 수록하여야 합니다.
- 내국인의 성명
성과 이름 사이에는 간격(공란)을 두지 말고 연이어서 수록합니다.
(예) 홍길동(○) 홍 길동(X)
남궁옥길(○) 남궁 옥길 (X)
- 외국인의 성명
   소리나는 대로 한글로 풀어서 수록합니다.
   (예) JAMES MARTIN→ “제임스마틴”

③ 주민등록번호(여권번호 등)

                          -4-
- 주민등록번호 사이에 "-"(하이픈 또는 마이너스)문자를 반드시 제거하여 숫자 13자리만
수록합니다.
   (예) 123456-1234567 → “1234561234567"

- 주민등록번호가 없는 자
   외국인등록번호, 여권번호, 재외국민등록번호등을 수록하며, 번호 사이의 "─" 또는 "/" 문자 등
   특수문자는 반드시 제거하여 좌측부터 수록하며, 13문자가 안될 때는 우측에 남는 자리를
   빈칸(Space)으로 둡니다.
- 주민등록번호의 구성체계는 다음과 같으며 작성시 오류가 없도록 유의하기 바랍니다.

⑥ 소재지(주소, 거소)
- 소재지(주소,거소)는 반드시 한글로 수록합니다.
- 도로명 주소로 우선 입력합니다. 단, 도로명주소가 없을 경우 지번주소로 입력합니다.
- 좌측부터 수록하고,우측에 남는 자리는 공란(Space)으로 둡니다
- (시.도), (구.시.군), (읍.면), (도로명), (건물번호), (통.층.호) (법정동, 공동주택명) 순서로 수록합니다.
- 특별시, 광역시, 도 명은 축약하여 수록하거나 생략할 수 있습니다.
     (예) "서울 특별시 영등포구 ….." → " 서울 영등포구 …. "(○)
      "서울 특별시 영등포구 ….." → " 영등포구…. "(○)
     "경상남도 …. "       → " 경남 …"(○)
- (구.시.군), (읍.면) 문자는 생략하지 않는 것을 원칙으로 합니다.
    생략하는 경우에는 항목 사이에 반드시 한 칸(1Byte)의 공란(Space)을 삽입하여야 하며,

⑦ 전화번호
- 전화번호의 지역(4자리), 국(4자리), 번호(4자리) 으로 수록합니다.
- 각각의 항목에 좌측부터 수록하고, 남는 자리는 공란(Space)으로 둡니다.
   (예) 서울시(02) 지역 647국 1234번 “02 647 1234"

   (예) 1995년3월27일 →“19950327" (월·일이 1단위일 경우 0을 앞에 수록)

⑨ 일련번호
- 일련번호는 순차적으로 부여합니다.
- 유효숫자는 우측을 기준으로 수록되어야 하며, 유효숫자 앞에는 반드시 빈칸(Space)을 두지말고
   0(Zero)으로 채워야 합니다.
   (예) 첫번째 일련번호(6자리로 구성)“000001"
- 수치(0~9) 이외의 공란, 문자 등이 있으면 안됩니다.

⑩ 수 치
- 수치항목(계산에 사용되는 항목)의 유효숫자 앞에는 0(Zero)로 채워야 하며, 수치항목이 음수인
경우는 ‘-‘ 부호(왼쪽에서 첫번째 자리에 기재)가 금액과 함께 표현되어야 하며, 유효길이는
‘-‘ 부호를 포함한 길이입니다.
- 값이 없는 경우에도 0(Zero)으로 채워야 합니다.
- 수치항목
· 일련번호, 제출건수
· 매출처수, 매입처수, 계산서매수, 금액

공란(Space)이 있어서는 안됩니다.
        (예) 세액이 5,230원인 경우 "0000005230"
            세액이 -5,230원인 경우 "-000005230"

● 유효숫자 : 유효숫자는 우측을 기준으로 수록되어야하며 음수인경우 ‘-‘를 표시합니다.

       (예) TYPE이 BIGINT(9)이면, 양수 : 100 →000000100
           음수 : -100 → -00000100

● 문자(숫자·영문자 포함) : 문자 또는 0~9까지의 숫자가 수록될 항목으로 좌로부터 수록하며,

                    우측에 남는 자리가 있는 경우에는 공란(Space)으로 둡니다.

뒤이어 다른 피상속인의 신고서와 첨부서류를 수록하는 식으로 생성하여야 합니다.

CHARCTER가 "Not Null" 이면 SPACE가 들어오면 오류

NUMERIC의 “Not Null default 0 이상" 의 경우는 numeric 0(zero)이상의 값이
들어오지 않으면 오류로 처리됩니다.
